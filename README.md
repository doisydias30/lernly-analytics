## Data model
TODO: lineage graph screenshot (`dbt docs generate` → `dbt docs serve`)

Raw CSV exports are cleaned in **staging** models (deduplication, mixed date
formats, German decimal commas, inconsistent labels), then modeled into a
**star schema** in the marts layer: `dim_users`, `dim_date`,
`fct_subscriptions`, `fct_payments`, `fct_weekly_activity`.
Every model has data-quality tests (uniqueness, not-null, accepted values,
referential integrity).

## Tech stack
SQL · dbt Core · DuckDB · Python (pandas, statsmodels) · Power BI · Git

## How to run it
```
python -m venv .venv
.venv\Scripts\activate          # Mac/Linux: source .venv/bin/activate
pip install dbt-duckdb
dbt build
python scripts/export_for_powerbi.py
```

## About the data
The dataset is synthetic, generated by `scripts/generate_data.py`, and
deliberately includes real-world messiness to clean.
